Client Script — Quantity Validation

Data integrity • O2C

Blocked quantity ≤ 0 on item sublist, preventing bad orders at source; reduced manual corrections.

SuiteScript 2.1Client ScriptSales Order
Code sample 
/**
 * @NApiVersion 2.1
 * @NScriptType ClientScript
 */
define(() => {
  const validateLine = (ctx) => {
    const qty = ctx.currentRecord.getCurrentSublistValue({ sublistId: 'item', fieldId: 'quantity' });
    if (qty <= 0) { alert('Quantity must be greater than 0'); return false; }
    return true;
  };
  return { validateLine };
});

User Event — VIP Order Auto-Flag

Prioritization • Fulfillment

Auto-set custbody_order_priority to High when VIP flag present; empowers Ops to prioritize pick/pack/ship.

SuiteScript 2.1User EventOrder Mgmt
Code sample 
/**
 * @NApiVersion 2.1
 * @NScriptType UserEventScript
 */
define([], () => {
  const beforeSubmit = (ctx) => {
    if (ctx.type === ctx.UserEventType.CREATE || ctx.type === ctx.UserEventType.EDIT) {
      const rec = ctx.newRecord;
      const vip = rec.getValue('custbody_vip_order');
      if (vip) {
        rec.setValue({ fieldId: 'custbody_order_priority', value: 'High' });
      }
    }
  };
  return { beforeSubmit };
});
